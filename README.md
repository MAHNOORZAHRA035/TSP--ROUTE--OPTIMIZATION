# Travelling Salesman Problem (TSP) Project

## Overview
This project implements the Travelling Salesman Problem (TSP) in C++ using:
- Greedy Algorithm
- Brute Force Algorithm

The program compares both algorithms based on:
- Total Cost
- Memory Usage
- Time Complexity
- Accuracy

## Features
- Create city database
- Save data into file
- Load saved data
- Display adjacency matrix
- Solve TSP using Greedy approach
- Solve TSP using Brute Force approach
- Compare algorithms
- Analyze memory and complexity
